# Field To Door Produce

Build a complete, modern, responsive web application prototype called "CropConnect".

TAGLINE:

"Fresh from Farmers, Direct to You."

CORE PROBLEM:

Farmers often depend on intermediaries to sell their fresh vegetables, which can reduce their profit and make it difficult to reach customers directly. Customers, meanwhile, may not know where their vegetables come from and may receive produce that is not sufficiently fresh.

SOLUTION:

CropConnect is a digital farmer-to-customer marketplace that allows farmers to list their freshly harvested vegetables directly on the platform. Customers can browse vegetables, see farmer information, select quantities, place orders, make payments, and track delivery.

The prototype must clearly demonstrate:

FARMER → CROPCONNECT → CUSTOMER → DELIVERY

IMPORTANT:

This is an SIH prototype/demo. Make it look like a real startup/product, not a generic template.

All important buttons and navigation should work.

Use realistic sample data.

Do not leave placeholder text such as "Lorem ipsum".

Make the application visually polished and presentation-ready.
